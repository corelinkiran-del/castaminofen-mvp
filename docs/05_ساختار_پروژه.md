## ۳. Development Setup

### ۳.۱ Prerequisites
```
- Node.js 20 LTS
- Docker & Docker Compose
- Git
- Yarn (package manager)
```

### ۳.۲ Initial Setup

```bash
# Clone repository
git clone https://github.com/your-org/absence-tracker2.git
cd absence-tracker2

# Install dependencies (root level)
yarn install

# Setup environment
cp .env.example .env.local

# Start all services
docker-compose up -d

# Run migrations
yarn run migrate
```

### ۳.۳ Development Commands

```bash
# Start all services in development mode
yarn dev

# Start specific service
yarn dev:auth-service
yarn dev:user-service
yarn dev:content-service

# Run tests
yarn test
yarn test:watch
yarn test:coverage

# Linting
yarn lint
yarn format

# Build all packages
yarn build

# Type check
yarn type-check
```

## ۶. Git Workflow

### ۶.۱ Branch Protection Rules

```
Main branch:
- Require PR review (2 approvals)
- Require status checks passing
- Require branches up-to-date
- Dismiss stale PR approvals
- Include admins in restrictions
```

### ۶.۲ Commit Convention

```
Format: {type}({scope}): {message}

Types:
  feat:     New feature
  fix:      Bug fix
  refactor: Code refactoring
  style:    Style changes
  test:     Test updates
  docs:     Documentation
  chore:    Maintenance

Examples:
  feat(auth): add OAuth2 Google login
  fix(media): resolve streaming buffering issue
  docs: update API documentation
```

## ۷. CI/CD Pipeline

### ۷.۱ GitHub Actions Workflows

**lint.yml:**
```yaml
- Run ESLint
- Run Prettier
- Type check TypeScript
```

**test.yml:**
```yaml
- Run Jest tests
- Generate coverage report
- Upload to Codecov
```

**build.yml:**
```yaml
- Build Docker images
- Push to registry
- Build Next.js static export
```

**deploy-staging.yml:**
```yaml
- Triggered on PR to develop
- Deploy to staging environment
- Run E2E tests
```

**deploy-prod.yml:**
```yaml
- Triggered on merge to main
- Deploy to production
- Verify deployment health
- Rollback on failure
```
